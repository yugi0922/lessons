CNNの畳み込みとプーリング

画像を扱うAIの多くは、CNN（畳み込みニューラルネットワーク）という仕組みを土台にしています。この記事では、その中心にある「畳み込み」と「プーリング」を、数字と動く図で一つずつ確かめます。最後に、画像生成AIの中で同じ部品がどう使われているかも見ていきます。

第1章

画像は数の格子

コンピュータにとって、画像は数が並んだ格子です。白黒の画像なら、1マス（1ピクセル）ごとに明るさを表す数が1つずつ入っています。よく使われるのは、0（黒）から255（白）までの整数です。

カラー画像は、赤・緑・青の3枚の格子を重ねたものです。この1枚1枚をチャンネルと呼びます。カラー画像は「高さ × 幅 × チャンネル数」の数の塊で、256×256ピクセルなら 256 × 256 × 3 = 196,608 個の数でできています。

ふつうのニューラルネットワークでは困ること

この数の塊を、そのまま一般的なニューラルネットワーク（全結合層）に入れると、困ったことが2つ起きます。

  • 調整する数が多すぎる。196,608個の入力を1,000個のニューロンにつなぐだけで、学習で調整する重みが約2億個になります。
  • 隣り合うマスの関係を活かせない。全結合層は入力を1列に並べて扱うので、どのマスが隣同士かという情報を使えません。写っている猫が10ピクセル右にずれただけで、まったく別の入力として扱われます。

CNNはこれを2つの工夫で解決します。1つは小さな範囲だけを見ること、もう1つは同じ道具を画像全体で使い回すことです。その道具が「畳み込み」です。

第2章

畳み込み

小さな窓をずらしながら、掛けて足す

畳み込みでは、まず3×3などの小さな数の表を用意します。これをカーネル（またはフィルタ）と呼びます。

カーネルを画像の左上に重ね、重なった9マスどうしで掛け算をして、9個の結果を合計します。この合計が出力の1マスになります。次にカーネルを1マス右にずらして同じ計算をし、右端まで行ったら1段下がって左端から続けます。最後までたどると、出力の格子が1枚できあがります。これを特徴マップと呼びます。

「縦のエッジ」のカーネルを四角にかけると、四角の左の辺でプラス、右の辺でマイナスの大きな値が出ます。全部0の場所や全部9の場所では、プラスとマイナスが打ち消し合って0になります。このカーネルは「左が暗くて右が明るい場所」を見つける検出器として働いているわけです。

カーネルの中身は学習で決まる

「縦のエッジ」や「ぼかし」は、画像処理で昔から使われてきたフィルタです。CNNでは、カーネルの9つの数を人が決めることはしません。たくさんの画像で学習するうちに、見分けるのに役立つ値へ自動的に調整されていきます。学習を終えたCNNの最初の層を調べると、エッジや色の境目に反応するカーネルができていることが知られています。

ストライドとパディング

ストライド
カーネルを一度に何マスずらすか。2にすると1マスおきに計算するので、出力の縦横はおよそ半分になります。
パディング
入力のまわりを0で囲むこと。囲まないと端のマスにはカーネルの中心が来ないので、出力は入力より少し小さくなります。3×3のカーネルなら、パディング1で入力と同じ大きさを保てます。
出力の一辺 ＝ ⌊（入力の一辺 ＋ 2 × パディング − カーネルの一辺）÷ ストライド⌋ ＋ 1

⌊ ⌋ は小数点以下の切り捨てです。上のデモでストライドとパディングを切り替えると、出力がこの式どおりの大きさに変わります。

本物の画像にかけてみる

同じカーネルを192×192ピクセルの画像にかけると、それぞれの働きが目で見てわかります。

カラー画像とフィルタの枚数

カラー画像のように入力が3チャンネルあるときは、カーネルも3枚重ねの 3×3×3 になります。27マスぶんを掛けて足し、1つの値を出します。

1種類のカーネルから得られる特徴マップは1枚です。実際のCNNでは、1つの層で数十から数百種類のカーネルを使います。64種類使えば、出力は64枚の特徴マップを重ねた「64チャンネル」の塊になります。

32×32×3入力（RGB）
∗
3×3×3カーネル × 64種類
→
32×32×64出力（パディング1）

この層で学習する数は、カーネルの重みが 3×3×3×64 = 1,728個、それに各カーネルに1つずつ付く足し算用の数（バイアス）が64個で、合計1,792個です。全結合層の約2億個と比べて桁違いに少なく、しかも画像が大きくなってもこの数は変わりません。同じカーネルを画像のどこでも使い回しているからです。

畳み込みの後のReLU

畳み込みの後には、たいていReLUという簡単な処理をはさみます。マイナスの値を0にして、プラスの値はそのまま通すだけの処理です。これがないと、畳み込みを何層重ねても全体が1回の「掛けて足す」にまとまってしまい、複雑な形を表せません。

第3章

プーリング

要点を残して、小さくまとめる

プーリングは、特徴マップを小さくまとめる処理です。よく使われるのは2×2の最大プーリングで、特徴マップを2×2の区画に分け、区画ごとに最大の値だけを残します。縦横がそれぞれ半分になり、マスの数は4分の1になります。区画の平均を残す平均プーリングもあります。

上の段と下の段を比べてみてください。下の段は、入力全体を1マス右にずらしたものです。最大プーリングでは、ずらす前と後で出力がまったく同じです。強い反応が同じ区画の中にとどまっている限り、位置が少し動いても結果は変わりません。平均プーリングに切り替えると、出力の値が変わることも確かめられます。

プーリングの役割

  • 計算を軽くする。マスの数が4分の1になるので、後ろの層の計算量とメモリが大きく減ります。
  • 小さなずれに強くなる。上のデモのように、数ピクセルの位置ずれで結果が変わりにくくなります。
  • 広い範囲を見られるようになる。縮めた特徴マップの上で3×3のカーネルを動かすと、元の画像ではもっと広い範囲を見ていることになります。次の章で詳しく見ます。

プーリングには、学習で調整する数がありません。決まった規則で最大値を選ぶか、平均をとるだけです。前の章の画像デモの右の2枚も、最大プーリングを1回、2回かけたものです。縦横が半分、4分の1になっても、輪郭の位置関係は残っています。

最近のネットワークでは、プーリングの代わりにストライド2の畳み込みで縮小することも増えています。縮め方そのものを学習で決められるからです。また分類用のCNNの最後では、各チャンネルの特徴マップ全体を平均して1つの数にまとめるグローバル平均プーリングがよく使われます。

第4章

層を重ねると何が起きるか

受容野と、浅い層から深い層への変化

受容野

3×3の畳み込みの出力1マスは、入力の3×3の範囲から計算されます。このように、出力の1マスに影響する入力の範囲を受容野と呼びます。

3×3の畳み込みをもう1回重ねると、2層目の1マスは1層目の3×3を見ていて、その9マスがそれぞれ入力の3×3を見ています。合わせると、2層目の1マスは入力の5×5を見ていることになります。

層を重ねるほど受容野は広がり、プーリングをはさむと一気に広がります。3×3の畳み込みと2×2の最大プーリングを交互に重ねると、次のようになります。

層処理1マスが見ている入力の範囲
13×3の畳み込み3×3
23×3の畳み込み5×5
32×2の最大プーリング6×6
43×3の畳み込み10×10
53×3の畳み込み14×14
62×2の最大プーリング16×16
73×3の畳み込み24×24

プーリングの後は特徴マップのマスが粗くなっているので、同じ3×3のカーネルでも、元の画像の上では2マスおき、4マスおきに広く見ていることになります。

浅い層から深い層へ

受容野が広がるにつれて、各層がとらえる特徴も変わっていきます。学習済みの画像分類CNNを調べると、おおむね次の傾向があることが知られています。

浅い層
線の向き、明るさや色の境目
中間の層
角、曲線、しま模様など、線の組み合わせ
深い層
目、車輪、文字など、物の部品
最後の層
「猫」「車」といった全体の判断

一般的な画像分類のCNNは、何回かの「畳み込み → ReLU」とプーリングをひとまとまりにして繰り返し、最後に全結合層で答えを出します。下の図は、代表的なVGG16というネットワークで、データの形がどう変わるかを示したものです。

縦横はだんだん小さく、チャンネル数はだんだん多くなっていきます。「どこにあるか」の細かい情報を少しずつ手放し、「何があるか」の情報を増やしていく流れです。

第5章

画像生成での使われ方

縮めて、広げて、つなぐ

ここまでの流れは、大きな画像を小さな答えにまとめるものでした。画像生成ではその逆に、小さな表現から大きな画像を作る必要があります。そこで、縦横を大きくする操作が加わります。

転置畳み込みで広げる

転置畳み込み（逆畳み込みと呼ばれることもあります）は、入力の1マスごとに「カーネル × そのマスの値」を出力にスタンプのように押していき、重なった部分は足し合わせる操作です。ストライド2で押していくと、出力の縦横はおよそ2倍になります。カーネルの中身は、普通の畳み込みと同じく学習で決まります。

カーネル3×3・ストライド2では、スタンプが重なる場所と重ならない場所が交互にでき、出力に1・2・4という格子状のムラが出ます。このムラは生成した画像に格子模様として現れることがあり、チェッカーボード・アーティファクトと呼ばれています。カーネルの一辺をストライドで割り切れる4×4にすると、ふちを除いて重なりが均一になります。

拡大してから畳み込む

もう1つの方法は、最近傍法やバイリニア補間でふつうに縦横2倍に拡大し、その後で普通の畳み込みをかけて整えるやり方です。重なりのムラが原理的に生じないので、チェッカーボード模様を避けたいときによく使われます。

DCGAN

2015年に発表されたDCGANは、CNNで画像を生成する手法の草分けです。画像が本物か偽物かを判定する識別器はストライド2の畳み込みで縮小し、画像を作る生成器は転置畳み込みで小さなノイズのベクトルを64×64の画像まで広げます。どちらもプーリングを使わず、縮め方と広げ方を学習に任せています。

U-Net

拡散モデルは、ノイズだらけの画像から少しずつノイズを取り除いて絵を仕上げる仕組みです。Stable Diffusion（1.x、2.x、SDXL）では、このノイズ除去をU-Netというネットワークが担っています。U-Netは前半で畳み込みと縮小を繰り返し、後半で拡大と畳み込みを繰り返して元の大きさに戻します。

縮めると「何が描かれているか」はつかめますが、細かい位置の情報は失われていきます。そこでU-Netは、縮める前の特徴マップを、同じ大きさまで戻った後半の層へ直接渡します。これをスキップ接続と呼びます。全体を見た判断と細部の情報を両方使えるのが、U-Netの強みです。

最初のU-Net（2015年、医療画像の領域分割のために作られたもの）は、縮小に2×2の最大プーリングを使っていました。拡散モデルのU-Netでは、ストライド2の畳み込みで縮小するものが多く見られます。

画像を圧縮・復元するVAE

Stable Diffusionは、画像を直接いじるのではなく、まず画像を小さな潜在表現に圧縮し、その上でノイズ除去を行います。Stable Diffusion 1.5の場合、512×512×3の画像を64×64×4に圧縮します。この圧縮と、最後に画像へ戻す復元を担当するのがVAEで、その中身も畳み込みと縮小・拡大の積み重ねです。

近年は、ノイズ除去の本体にTransformerを使うモデル（Stable Diffusion 3やFLUXなど）も増えています。それでも、潜在表現への圧縮と復元には、いまも畳み込みのネットワークが広く使われています。

第6章

コードで形を確かめる

PyTorchでは、ここまでの部品をそれぞれ1行で用意できます。コメントの中の4つの数は、処理の後のテンソルの形（バッチ, チャンネル, 高さ, 幅）です。

import torch
import torch.nn as nn

x = torch.randn(1, 3, 64, 64)  # 64×64のカラー画像が1枚

conv = nn.Conv2d(3, 16, kernel_size=3, padding=1)        # 3×3の畳み込み 3ch → 16ch
pool = nn.MaxPool2d(kernel_size=2)                        # 2×2の最大プーリング
down = nn.Conv2d(16, 32, kernel_size=3, stride=2, padding=1)  # ストライド2で縮小
up   = nn.ConvTranspose2d(32, 16, kernel_size=4, stride=2, padding=1)  # 転置畳み込みで拡大

h = conv(x)   # → (1, 16, 64, 64)  パディング1なので大きさはそのまま
h = pool(h)   # → (1, 16, 32, 32)  縦横が半分
h = down(h)   # → (1, 32, 16, 16)  ここでも縦横が半分
h = up(h)     # → (1, 16, 32, 32)  縦横が2倍に戻る

print(sum(p.numel() for p in conv.parameters()))  # 448 = 3×3×3×16 + 16

転置畳み込みの出力の一辺は、（入力の一辺 − 1）× ストライド − 2 × パディング ＋ カーネルの一辺 で決まります。この例では (16 − 1) × 2 − 2 + 4 = 32 です。

第7章

まとめ

操作何をするか縦横の大きさ学習する数
畳み込み小さな窓をずらしながら掛けて足すパディング1で同じ／なしで少し縮むあり（カーネル）
ストライド2の畳み込み1マスおきに畳み込む約1/2あり
最大・平均プーリング区画の最大値か平均を残す1/2（2×2のとき）なし
転置畳み込み1マスごとにカーネルを押して足し込む約2倍（ストライド2のとき）あり
拡大＋畳み込み補間で拡大してから畳み込む2倍あり（畳み込みの部分）
  • 畳み込みは、小さなパターン検出器（カーネル）を画像全体に走らせる操作です。検出器の中身は学習で決まります。
  • プーリングは、要点だけを残して縮める操作です。計算が軽くなり、小さな位置ずれに強くなり、後ろの層が広い範囲を見られるようになります。
  • 画像生成では、縮める部品に広げる部品（転置畳み込みや、拡大＋畳み込み）を組み合わせ、U-NetやVAEといった形で使われています。
